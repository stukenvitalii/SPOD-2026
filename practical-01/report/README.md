# Отчёт по первой практической

Актуальный документ — `Практическая работа 1 цветные графики.docx`. Все страницы — книжный A4, текст — Times New Roman 14, текст и заголовки чёрные, графики цветные. Титульного листа нет; первая страница имеет номер 2. Перед отправкой вставить титульный лист по своему образцу. При объединении документов сохранить книжный формат A4 во всех разделах.

Отчёт содержит оба задания, модели, полный код, снимок реального запуска, пять повторов произвольного вывода, таблицы медианного времени, графики времени и формального отношения T1/Tp, анализ и инструкции воспроизведения. Замеры выполнены на Windows, на текущем компьютере, 28 октября 2026 года.

`measurements.csv` — 180 первичных измерений: две версии × шесть чисел процессов × три размера сообщения × пять повторов. Одна серия содержит 1000 раундов. Исходные результаты не изменены; медианы вычисляются при сборке документа. `examples.json` содержит пять реальных порядков вывода при восьми процессах.

`build_report.py` собирает DOCX и графики из сохранённого `measurements.csv`; нужны Python, python-docx и Pillow. Сначала можно установить зависимости командой `python -m pip install -r practical-01/report/requirements.txt`, затем запустить `python practical-01/report/build_report.py`. Сборка перезаписывает документ, поэтому перед ней сохраните копию, если вносили изменения вручную.

В `assets/runs.png` хранится исходный снимок терминала. Графики и обрезки генерируются заново и не включаются в Git. `render_word.ps1` использует скрытый экземпляр установленного Word для локальной проверки страниц; временная папка `qa/` не нужна для сдачи.

Примечание к данным: при одном процессе обмен отсутствует, поэтому формальное отношение T1/Tp не является ускорением фиксированной полезной нагрузки. Это ограничение подробно указано в документе.
